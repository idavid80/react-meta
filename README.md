# Certificación Profesional: **Meta Front-End Developer**

Este repositorio contiene los proyectos y aprendizajes obtenidos durante la certificación **Meta Front-End Developer**, ofrecida por Meta a través de Coursera. La certificación consta de 9 cursos intensivos diseñados para preparar a los estudiantes para una carrera como desarrolladores front-end.

---

## 🏆 **Descripción del programa**

¿Quieres iniciarte en el mundo de la programación y construir sitios web como una carrera profesional? Este programa, desarrollado por expertos en ingeniería de software de Meta, te equipa con las habilidades necesarias para desempeñarte como desarrollador front-end.  

### Lo que aprenderás:
- Cómo codificar y construir páginas web interactivas utilizando **HTML5**, **CSS** y **JavaScript**.
- Habilidades de diseño en demanda para crear páginas profesionales usando herramientas estándar como **Bootstrap**, **React** y **Figma**.
- Control de versiones con **GitHub**, gestión de contenido con CMS y edición de imágenes con Figma.
- Cómo prepararte para entrevistas técnicas para roles de desarrollador front-end.

### Proyectos prácticos:
- Edición de tu página de biografía utilizando **HTML5**, **CSS** y marcos de interfaz de usuario.
- Gestión de un proyecto en GitHub aplicando control de versiones y comandos de terminal Linux.
- Construcción de una versión estática de una aplicación utilizando **React**, hooks, enrutamiento, bundlers y obtención de datos.
- Desarrollo de un proyecto final donde crearás tu propia aplicación web front-end.
